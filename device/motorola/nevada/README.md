Codename: `nevada`. Model: `XT2615-1` (RETUS). SoC: `mt6835`.

## Source layout

- `device/motorola/nevada` — this tree (Lineage 23 / Android 16)
- `vendor/motorola/nevada` — proprietary blobs (generated by `extract-files.py`)
- `device/motorola/nevada-kernel` — prebuilt kernel + DTB + modules (see below)
- Kernel source: `https://github.com/MotorolaMobilityLLC/kernel-mtk`
  branch `android-16-release-w1wn36.18-114` (matches `W1WNS36.18-114-1` firmware)

Kernel DTS in that repo:

- `arch/arm64/boot/dts/mediatek/mt6835-nevada-common-overlay.dtsi`
- `arch/arm64/boot/dts/mediatek/mt6835-nevada-evb-overlay.dts`
- `arch/arm64/boot/dts/mediatek/mt6835_nevada_camera_overlay_evb.dtsi`
- `arch/arm64/boot/dts/mediatek/nevada-*.dtsi` (audio/display/touch/fps/sensor/charger/...)

## Blob extraction

1. Extract firmware zip, reassemble `super.img` from sparsechunks
   (`simg2img` / `lpunpack`), mount or use `extract-files.py` against
   a running device (`adb root`) or against extracted dumps:

   ```bash
   cd device/motorola/nevada
   ./extract-files.py /path/to/extracted/super_mnt
   # or connected device:
   ./extract-files.py
   ```

2. This regenerates `vendor/motorola/nevada/` via `setup-makefiles.py`.
   Current `proprietary-files.txt` is a 1483-line MT6835/MTK template
   inherited from manaus — prune/augment after first extraction and
   fix `blob_fixups` in `extract-files.py` per pull errors.

## Build (after `repo sync` completes + blobs pulled)

```bash
source build/envsetup.sh
lunch lineage_nevada-userdebug
m bacon   # or: m otapackage
```

Prebuilt-kernel flow is enabled by default
(`TARGET_FORCE_PREBUILT_KERNEL := true`). Populate
`device/motorola/nevada-kernel/` with `Image.gz`, `dtb/`, `vendor/*.ko`,
`vendor_ramdisk/*.ko`, `modules.load.*` from a `kernel-mtk` build or from
firmware `boot`/`vendor_boot`/`vendor_dlkm` images before building.

To build kernel from source (`/home/builder/kernel-mtk`), use
`build.config.mtk.aarch64` / GKI `android13-5.15` flow, then copy outputs
into `device/motorola/nevada-kernel/`.
